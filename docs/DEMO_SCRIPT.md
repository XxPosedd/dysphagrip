# 2-minute demo script

1. **Problem (20 sec):** Explain that swallowing difficulties can be difficult to monitor outside clinical settings. Avoid claiming this prototype diagnoses aspiration.
2. **Show inputs (20 sec):** Start browser microphone capture; show the live audio level. Show the MPU-6050 only if live readings have been verified.
3. **Show analysis (30 sec):** Mark a candidate audio event manually or use a clearly labeled experimental event detector. Show movement interference as a separate signal-quality condition.
4. **Show sponsors (30 sec):** Read a UI status aloud with ElevenLabs; save and reload a session from Neon; show a sourced public-resource record if Bright Data integration is live.
5. **Close (20 sec):** State limitations and next validation steps.

Fallback: use a clearly labeled prerecorded sample and a demo database session if venue Wi-Fi, permissions, or hardware fails. Never present simulated data as live.
